# Live capture 데이터·보안 사람 검토 양식

> 상태: `PENDING_HUMAN_REVIEW` · 작성: 2026-09-19
>
> 이 문서는 E3·L5 결정을 위한 빈 양식이다. 현재 실제 CNU 자료의 추가 사용·공유나 실제 데이터 배포·외부 시연에 대한 승인이 없다. 완전 합성 입력의 로컬 개발 검증과는 구분한다.

## 작성 원칙

- 데이터 책임자와 보안 검토자가 실제 수집 **전에** 범위를 채우고 결정한다.
- 실제 질문·응답·SQL·DB 행, 식별값, 프롬프트, 절대 경로, 비밀키를 이 문서에 복사하지 않는다. 필요한 증거는 접근 통제된 별도 기록의 식별자만 남긴다.
- `--check` 성공은 입력·경로의 기술적 사전 점검 결과다. `--live` 지정이나 과거 합성 smoke도 사람 승인 근거가 아니다.
- 보류나 미기입 상태에서는 실제 CNU 자료의 live capture·공유와 실제 데이터 배포·외부 시연을 시작하지 않는다. 합성 입력의 로컬 private 검증은 계속할 수 있다.
