## 2. 열린 질문

1. 가장 헷갈리거나 답답했던 순간은 언제였나요?
2. 결과를 **믿지 못했던** 순간이 있었나요? 반대로, 확인 없이 믿었던 결과가 있었나요?
3. 챗봇이 이해한 조건이 내 뜻과 달랐던 적이 있나요? 그때 알아차렸나요?
4. 이 화면에서 하나만 바꾼다면 무엇을 바꾸고 싶나요?
5. (관리자 과제를 했다면) 처음 보는 말이나 막힌 단계가 있었나요?
